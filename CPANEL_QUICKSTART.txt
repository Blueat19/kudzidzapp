STEP 1: PREPARE FILES LOCALLY
-----------------------------
# Build frontend
cd frontend
yarn install
npx expo export --platform web
# Creates 'dist' folder with all frontend files


STEP 2: SETUP MYSQL DATABASE
----------------------------
1. In cPanel, open "MySQL Databases"
2. Create database (example: tangakudzidza)
3. Create MySQL user and password
4. Add user to database with "ALL PRIVILEGES"
5. Note your values for:
   - MYSQL_HOST (usually localhost)
   - MYSQL_PORT (usually 3306)
   - MYSQL_USER
   - MYSQL_PASSWORD
   - MYSQL_DATABASE


STEP 3: DEPLOY BACKEND TO CPANEL (NODE APP)
-------------------------------------------
1. Login to cPanel: https://yourdomain.com:2083

2. Go to "Setup Node.js App" (or "Node.js Selector") and create app:
   - Node.js version: 18+
   - Application mode: Production
   - Application root: tangakudzidza_api
   - Application URL: yourdomain.com/api (or api.yourdomain.com)
   - Application startup file: app.js

3. Upload these files to tangakudzidza_api folder:
   - app.js
   - server.js
   - package.json
   - .env (create from .env.example)

4. Create .env file:
   ---------------------------
   MYSQL_HOST=localhost
   MYSQL_PORT=3306
   MYSQL_USER=your_mysql_user
   MYSQL_PASSWORD=your_mysql_password
   MYSQL_DATABASE=tangakudzidza
   ALLOWED_ORIGINS=https://yourdomain.com,https://www.yourdomain.com
   PORT=3000
   ---------------------------

5. Install dependencies and restart app:
   - In Node.js App UI, click "Run NPM Install"
   - Click "Restart"


STEP 4: DEPLOY FRONTEND TO CPANEL
---------------------------------
1. Go to File Manager > public_html

2. Upload ALL contents of 'dist' folder:
   - index.html
   - _expo/ folder
   - assets/ folder

3. Create .htaccess file in public_html:
   ---------------------------
   <IfModule mod_rewrite.c>
     RewriteEngine On
     RewriteBase /
     RewriteCond %{REQUEST_FILENAME} !-f
     RewriteCond %{REQUEST_FILENAME} !-d
     RewriteRule ^ index.html [L]
   </IfModule>
   ---------------------------


STEP 5: TEST
------------
Frontend: https://yourdomain.com
Backend:  https://yourdomain.com/api/health


TROUBLESHOOTING
---------------
500 Error: Check Node.js app logs in cPanel
404 Error: Check .htaccess file exists
CORS Error: Update ALLOWED_ORIGINS and restart backend
